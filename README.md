# Capi — piloto fechado

Este repositório é **alvo de deploy automático**: ele guarda apenas os arquivos do app que o
GitHub Pages serve. Não edite nada aqui — todo commit é sobrescrito pelo CI do repositório de
origem, que é privado.

O piloto está em teste com um grupo pequeno e o acesso é por convite. Se você recebeu um link com
código, ele entra sozinho.

**A Capi é uma capivara que vive da sua rotina saudável**: beber água, comer bem e se movimentar.
Ela nunca morre, nunca pune e nunca gera culpa — a zoeira é afetuosa.

Instalável como app: abra no celular e use "Adicionar à tela de início".

Dúvidas ou feedback: use o botão "Mandar feedback do piloto" dentro do app (Perfil).
